# Resultados derivados

Cada equipo debe crear su propia carpeta, por ejemplo `resultados/equipo01/`.
En Git se conservan métricas, resúmenes, PSD y figuras que no permitan
identificar a la persona participante. Los archivos `*_procesada.csv`, que
contienen la serie temporal muestra por muestra, permanecen únicamente en la
computadora de trabajo y están excluidos mediante `.gitignore`.
